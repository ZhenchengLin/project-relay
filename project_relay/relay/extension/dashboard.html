How Relay ADE works

PM · Claude (claude.ai)

The strong model. Reads the goal and your rules, plans one small task at a time, reviews risky commands before they run, reads the real terminal evidence and decides when the goal is done.

Worker · ChatGPT (chatgpt.com)

Turns each task into exactly one Bash block. It never decides what comes next; the PM does.

Relay · your Mac

The extension moves messages between the two chats in your own signed-in Chrome; prelayd runs the Bash in your repo, records everything in SQLite, runs the local loop judges and enforces the safety rules.

You · this tab

Watch, pause or stop, and answer when the PM asks for a human (RELAY_ASK_HUMAN). Keep this tab pinned.

One step

Safety rules (always on)

  • One message is sent at most once. Anything re-sent is a new, logged request.
  • A reply is used only when it is final, never while Claude or ChatGPT is still writing.
  • Cut-off scripts (unclosed heredocs, bash -n errors) never run.
  • Blocked outright: sudo, reset --hard, clean -f, stash, checkout --, restore, force push, rm -rf ~, … (also with git -C / -c options).
  • A command that started is never re-run after a crash; the PM is told instead.
  • Everything is in ~/.project-relay/relay.db and prelay log PROJECT.

Review policy

  • risky (default): the PM must approve commits, pushes, merges, deletes, moves, permission changes, package installs, curl | sh and scripts over 200 lines.
  • always: every command. Safest, uses the most Claude messages.
  • never: no pre-run review; the PM still sees every result.

Supervisor, memory and plan

  • Alerts: a desktop notification when a run needs you, pauses, finishes, or has been idle too long.
  • Budgets and quiet hours (supervisor in config.json): daily Claude/ChatGPT message caps, and hours when Relay sends nothing new.
  • Memory: facts the project must never forget (RELAY_NOTE: from the PM, or added here); they go into every new chat, so rollovers keep them.
  • Plan: the PM keeps a RELAY_PLAN checklist; progress shows on each run.

Tips

  • Use Arrange windows: Claude and ChatGPT side by side and visible. Hidden tabs make both sites slow down replies.
  • Two loop verdicts in a row stop the run for you.
  • Long chats roll over automatically: the model writes a handoff and Relay continues in a new chat.
  • Automating chatgpt.com and claude.ai is unofficial; keep a human pace.
